## Задача 5
### Текст задачи
Добавление массива в массив.  
Дана сигнатура метода: public int[] add (int[] arr, int[] ins, int pos); 
Необходимо реализовать метод таким образом, чтобы он возвращал новый 
массив, который будет содержать все элементы массива arr, однако в позицию 
pos будут вставлены значения массива ins. 
 
Пример: 
arr=[1,2,3,4,5] 
ins=[7,8,9] 
pos=3 
результат: [1,2,3,7,8,9,4,5]
### Алгоритм решения
Создаётся новый массив целых чисел new_arr с длинной равной длине массивов arr и ins вместе, заполненный нулями. Затем создается логическая переменная pasted, равная false. После в цикле for с итератором i (от 0 до длины массива new_arr) происходит редактирование массива new_arr по следующим правилам: если i больше или равен значению аргумента pos и i больше суммы pos и длины массива для вставки, то i-ый элемент массива new_arr становится равен элементу из массива ins, стоящему на позиции i - pos, а также переменная pasted становится равной true. Иначе же если переменная pasted - истина, то i-ый элемент массива new_arr становится равен элементу из массива arr, стоящему на позиции i - длина ins. В противном случае i-ый элемент массива new_arr становится равен i-ому элементу из массива arr. После завершения цикла возвращается массив new_arr.

## Задача 9
### Текст задачи
Все вхождения.  
Дана сигнатура метода: public int[] findAll (int[] arr, int x); 
Необходимо реализовать метод таким образом, чтобы он возвращал новый 
массив, в котором записаны индексы всех вхождений числа x в массив arr. 
 
Пример: 
arr=[1,2,3,8,2,2,9] 
x=2 
результат: [1,4,5]  
### Алгоритм решения
Сначала создаётся переменная-счётчик и с помощью первого цикла for устанавливается количество вхождений искомого элемента в массив путём увеличения счётчика на 1 в случае соответствия итератора цикла с нужным значением. После этого создаётся массив indexes, длина которого равна значению счётчика, а также вводится переменная i, хранящая текущее индекс для добавления очередного значения в массив indexes. Затем вторым циклом for значения массива arr поочерёдно сравниваются с искомым значением, и в случае равенства значение итератора сохраняется в массиве indexes на i-ой позиции, а значение переменной i увеличивается на 1. В конце возвращается массив indexes.
